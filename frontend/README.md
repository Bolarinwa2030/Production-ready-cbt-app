# Ascend Exam Suite

You are a Senior Product Designer, Senior UI/UX Designer, and Senior React Frontend Engineer.

Your task is to design the frontend UI for a production-ready Computer-Based Testing (CBT) Platform.

IMPORTANT:

Do NOT generate backend code.

Do NOT generate API integrations.

Do NOT use mock authentication logic.

Focus only on the frontend UI and user experience.

The design should look like a premium SaaS platform used by universities, certification providers, and enterprise organizations.

The interface should feel comparable in quality to Notion, Linear, Stripe Dashboard, Vercel, or Coursera.

The UI must be modern, clean, highly responsive, accessible, and production-ready.

Use reusable React components.

Support both Dark Mode and Light Mode.

Use a professional design system with consistent spacing, typography, cards, buttons, tables, forms, dialogs, and navigation.

The platform should support Students, Instructors, and Administrators.

For this phase, ONLY build the Student Portal.

Generate the following pages:

1. Landing Page

- Hero section

- Features

- Call-to-action

- Testimonials

- Footer

2. Login Page

3. Registration Page

4. Forgot Password

5. Student Dashboard

Include:

- Welcome card

- Upcoming Exams

- Practice Exams

- Recent Scores

- Performance Summary

- Notifications

- Calendar Widget

- Leaderboard Preview

6. Available Exams

Display:

- Exam title

- Subject

- Duration

- Number of Questions

- Difficulty

- Start Button

7. Exam Instructions Page

Display:

- Rules

- Timer

- Number of Questions

- Allowed Attempts

- Start Exam Button

8. Exam Interface

Include:

- Question navigation sidebar

- Timer

- Question card

- Multiple choice options

- Previous

- Next

- Flag for Review

- Progress Indicator

- Remaining Questions

9. Review Answers Page

10. Submission Confirmation Dialog

11. Result Page

Include:

- Score

- Pass/Fail

- Performance Charts

- Correct Answers

- Wrong Answers

- Review Button

12. Exam History

13. Student Profile

14. Settings

15. Notifications

Requirements:

- Responsive design

- Mobile friendly

- Tablet friendly

- Desktop optimized

Use modern icons.

Use reusable layouts.

Create reusable UI components instead of duplicating code.

The project should be organized so that it can later integrate with a Node.js backend through REST APIs.

Do not implement backend functionality.

Only generate the frontend application.
